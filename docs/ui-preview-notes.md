## 悬浮窗优先的设计补充

补充预览 `bubble-floating-flow.html`（同一可视化目录），以完整第三方视频页面为背景，演示浮球、浮窗交办、任务回执、后台处理、结果和浮窗追问。只使用演示内容，计时器模拟完成，不请求后端或模型。

- 在小窗内就能完成贴链接 → 交办 → 查看结果 → 继续追问。主应用承担历史管理与长文阅读。
- 右上角加号新建；仅链接必填，任务要求可选展开，默认总结重点。
- 收起保留后台执行；完成时只改变浮球标记，不主动展开遮住正在看的内容。
- 标题栏可拖动；小窗周围不加遮罩；来源与处理依据随结果保留。
- 键盘出现时浮窗上移，正文区缩短并可滚动，追问和发送始终保持可见。
- 最近对话与原会话追问在小窗内切换；长结果可进入完整应用阅读。
- 抓取失败返回登录/重试出口；没收到后台回执时保留输入并显示待重试，不显示正在后台执行。

安卓服务已改为宽度最多 360dp、高度最多 470dp 的小窗，标题区域可拖动，键盘弹出时按可见区域调整窗口。浮球用处理状态和持久化未读标记提示任务进展；完成不主动展开窗口。新建页的提交按钮和结果页的追问区固定在底部，正文滚动。完整阅读入口传递原会话 ID。实际手机验收另记，构建通过不等于真机行为全部通过。
