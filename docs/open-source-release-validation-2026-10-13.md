# 首次开源整理与验证

2026-10-13，用户授权公开项目。公开仓库采用 MIT，保留 Gradle Wrapper 等第三方的许可证与版权头；APK 内附许可证资料。项目使用 AI 辅助开发，复用组件与本仓应用实现的范围见 README。

## 公开内容与隐私处理

公开源码、构建入口、配置模板、自动化测试、研究与技术验收文档。不公开 `.env`、模型/服务凭据、Cookie、浏览器登录态、SQLite、来源/结果/会话、工具与模型下载目录、签名私钥、个人求职材料及私人开发约定。

部分历史文档中的本机路径、设备序列号已替换为占位符；文章 fixture 移除个人分享追踪参数，保留公开文章 URL。原始本机文档在忽略目录保留，技术结论、旧阶段和未完成项没有改写成新验收。公开文档引用的私人运行报告不随仓库分发。

仓库提供凭据审计脚本；存在本机配置时比对四类实际凭据，无配置时检查一般 key / token / 私钥形态。APK 扫描解压后的所有条目，不仅比较压缩文件字节。扫描通过不等于任意形式的秘密探测保证。

## 自动构建与使用边界

GitHub Actions 配置 Linux / Windows 后端检查，以及 JDK 17 / SDK 35 安卓构建、单元测试、lint 和 APK 审计。远端运行结果以仓库 Actions 为准，不用本机通过代替远端成功。

首轮远端检查暴露新环境假设：启动器测试在忽略的 `.tools` 目录不存在时 `mkdtemp` 报 ENOENT；安卓 runner 没有可用的 `sdkmanager`。全新克隆复现前者后，测试显式创建自己的临时目录父级，CI 使用固定版本的 Android SDK setup action 安装工具链；不要求使用者带入开发机的工具目录。

第二轮 Linux 后端及安卓构建通过，Windows 音轨降级用例暴露实际路径兼容问题：下载文件已取 `realpath`，工作目录仍是短路径/目录链接表示，字符串包含检查误拒绝合法音轨。新增 junction/目录链接回归先复现失败，再规范化工作根路径；合法音轨通过，目录外音轨仍拒绝。视频测试 15 / 15 通过，应用测试数量因此从 73 增至 74。这验证本地受控文件路径，不等于新的视频实网转写或准确率测评。

公开预览 APK 使用 debug 签名，需要用户自行配置后端。模型 key 不放在 APK，网站访问限制与手机系统权限仍需要用户处理。个人知识库集成默认关闭，需要独立兼容网关。历史来源获取、真实模型、ASR、缓存和手机验收按各自报告的日期、环境与范围阅读。
