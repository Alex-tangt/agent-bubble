# Qwen 文件转写接入与验收

日期：2026-10-09。官方接口依据见 [调研记录](qwen-asr-integration-research-2026-10-09.md)。凭据保存在私有 `.env`；没有写入文档、前端或 APK。

## 当前行为

字幕优先。平台字幕不可用时下载当前 P 的纯音轨，采用用户指定的 `qwen-audio-3.0-asr-flash-filetrans`：申请上传凭证 → 上传临时 OSS → 提交异步任务 → 保存任务回执 → 查询状态 → 取得全文和句子时间戳 → 校验完整时长 → 总结与同会话追问。

北京地域 `https://dashscope.aliyuncs.com/api/v1` 上传凭证验证通过；新加坡接口对本次凭据返回鉴权失败，未向该地域提交转写。`parameters`、`file_urls`、异步和 OSS 解析请求头按官方 HTTP 接口设置。只识别第一个音轨，没有新开通对象存储或额外云凭据。

配置 `DASHSCOPE_API_KEY` 且不指定 `ASR_PROVIDER` 时自动选择 Qwen；也可显式设置 `ASR_PROVIDER=qwen`。`ASR_PROVIDER=local` 保留本地模式。已配置云端时，云端鉴权 / 额度 / 任务错误给出结构化提示，不自动退回耗时更长的本地识别。

使用用户原链接 `BV1t2HQ6EEaD/?p=1`，原音轨 **603.268 秒**。由于这个视频登录后有字幕，仅验收脚本主动跳过字幕，以验证真实云端降级；生产代码继续字幕优先。

## 状态、重试与取消

临时上传文件按平台规则在 48 小时后清理。这是自用规模的接法；正式部署需改用稳定对象存储。[官方临时上传说明](https://help.aliyun.com/zh/model-studio/get-temporary-file-url)

云任务 ID 与完成的全文保存在私有 `data/qwen-asr/jobs/`，按音轨内容、地域、模型和凭据的哈希区分。已知任务中断后可继续查询，已完成的全文直接复用。提交网络结果未知时不自动重复提交，避免不明确的重复调用。结果下载与临时 OSS 上传不携带模型 Bearer key。

本地停止等待时，仅排队中的 `PENDING` 任务可远端取消。已开始的云任务可能继续运行并计费，其回执保留供重试查询；后端重启不会把未保存的部分转写当成完整来源。[官方任务管理](https://www.alibabacloud.com/help/en/model-studio/manage-asynchronous-tasks)

## 验证与手机使用

后端全套 **55 / 55** 测试通过，另对最后修改的流式文件校验及健康接口复测 25 项，TypeScript 和网页脚本语法通过。覆盖私有上传、指定模型、异步查询、时间戳、完整时长、子任务失败、断点查询、取消、提交不确定性、凭据脱敏和子进程隔离；既有文章与会话测试也通过。

后台已重新编译并更新，手机现有 APK 兼容。手机继续分享视频链接即可；两条原链接已有平台字幕缓存，仍走字幕。无可用字幕的新来源会显示上传、Qwen 转写及总结进度。API key 不需要填到手机，模型摘要仍使用原 DeepSeek 配置。

可以运行 `npm run test:qwen` 独立验收原 10 分钟视频的真实云端路径，包含模型调用；这只影响验收目录，不会覆盖正常服务已有平台字幕。设置 `ASR_PROVIDER=local`、重启后台即可回到本地转写。
