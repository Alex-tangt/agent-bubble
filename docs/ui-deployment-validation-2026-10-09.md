# 收件匣与悬浮窗实施、部署记录

已按用户批准的第 3 套收件匣及悬浮窗原型重写 Kotlin / Compose 页面。主界面是历史收件匣，右上角加号新建，只要求链接，任务要求默认折叠；支持系统分享带链接的文字。普通页面移除正文、字幕和文件导入。结果保留来源、字幕 / 转写依据，支持分享及原会话追问。

悬浮窗最多 360dp × 470dp，标题区域拖动，窗外无遮罩；新建提交与结果追问固定在底部，内容区滚动。收起不会取消已接收任务；完成只通知和改变浮球标记，不展开窗口。未读状态保存到本地，完整阅读入口传递会话 ID。关闭窗口前编辑的链接仍保留。无法连接时，可以打开最近缓存的结果。
